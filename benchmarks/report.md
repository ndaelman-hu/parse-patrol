# Parser Reliability Benchmark — Multi-Parser Report

Generated by `benchmarks/report.py` from `results.csv`. Corpus: real computational-chemistry files from the NOMAD repository, frozen in `dataset.json`.

**Success** = the parser extracted an atomic structure (atoms + coordinates) without raising. **Empty** = no exception but no structure (a *silent* failure). **Error** = exception raised. **Timeout** = exceeded the per-file budget.
